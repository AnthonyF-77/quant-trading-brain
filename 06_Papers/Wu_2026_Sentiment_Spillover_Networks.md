# Do News and Social Media Tell the Same Story? Sentiment Spillover Networks

**来源**: arXiv [#2604.26811](http://arxiv.org/abs/2604.26811)
**日期**: 2026-04-29
**分类**: 03_Alpha_Factors
**标签**: #情绪因子 #社交媒体 #NLP #信息溢出

## 核心观点

1. 投资者情绪影响投资决策，信息会从一家公司溢出到同行业其他公司
2. 使用**网络传递熵方法**测量新闻和社交媒体情绪的信息传导
3. **发现**: COVID-19 后科技公司之间的新闻信息流强度显著增加
4. 新闻和社交媒体呈现**不同的信息传导模式**，不可互换使用
5. 识别出科技板块中的**信息 hub 公司**和**最强信息流链**

## 可执行见解

- **Alpha 因子**: 新闻情绪 + 社交媒体情绪是两种不同的信号，不可混用
- **因子组合**: 在预测科技股收益时，应分别处理新闻情绪因子和社媒情绪因子
- **行业轮动**: 可用信息溢出网络识别哪些公司在行业情绪传导中处于领导地位

## 局限性

- 仅研究科技公司
- 传递熵方法对数据质量敏感
