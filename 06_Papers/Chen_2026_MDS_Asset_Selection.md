# Large-Scale Asset Selection via Metric Dependence with Enriched High Frequency Information

**来源**: arXiv [#2605.02326](http://arxiv.org/abs/2605.02326)
**日期**: 2026-05-04
**分类**: 03_Alpha_Factors
**标签**: #资产选择 #高频数据 #因子 #中国A股 #组合优化

## 核心观点

1. **问题**: 大规模组合选择对估计误差高度敏感，初步资产筛选至关重要
2. 现有选择规则仅依赖标量收益或低维高频汇总，**丢弃日内风险动态**
3. 提出 **Metric Dependence Screening (MDS)**：
   - 将每个资产日表示为**点-曲线对象**（日收益 + 日内风险状态曲线）
   - 加权乘积度量保持收益信息和日内风险动态
   - 基于 Fréchet 变异的依赖分数排名资产
4. 两阶段程序：MDS 先降低投资范围 → 标准均值方差或最小方差分配
5. **实证**: 2023.7-2025.12 中国A股 2938 只股票，5 分钟数据，MDS 优于所有基准

## 可执行见解

- **资产选择**: 加入日内风险动态（而非仅日收益）能显著改进选股质量
- **中国市场**: MDS 在 A 股有效（高波动、日内动态丰富的市场更适用）
- **流程**: 大规模筛选 → 低频组合优化 = 兼顾效率和精度

## 局限性

- 仅中国 A 股市场
- 日内风险曲线计算对数据质量要求高
