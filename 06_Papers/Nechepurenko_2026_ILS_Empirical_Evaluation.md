# Empirical Evaluation of Deadline-Resolved ILS on Polymarket Insider Cases

**来源**: arXiv [#2605.02286](http://arxiv.org/abs/2605.02286)
**日期**: 2026-05-04
**分类**: 03_Alpha_Factors
**标签**: #信息泄漏 #Polymarket #ILS #预测市场

## 核心观点

1. 评估 deadline-ILS 扩展在 2026 年美伊冲突 cluster 上的表现
2. **Hazard-rate 估计**: 军事-地缘政治市场指数拟合良好（KS p=0.609，半衰期 2.3 天）
3. 在最大适用 FFIC 合约上（"US forces enter Iran by April 30", $269M 成交量），ILS-dl = +0.113（文章时间戳）vs -0.331（代理）
4. 移动 **0.444 幅度**，在零的两侧 — 证明 deadline-ILS 能区分信号和代理伪影
5. 跨市场钱包分析：识别出 332 个同时在两个主要伊朗 cluster 市场中活跃的钱包

## 可执行见解

- **Alpha**: deadline-ILS 是预测市场内幕交易检测的可行工具
- **信号解读**: 仅看 ILS 分数不够，需理解 resolution 类型
- **研究方向**: 结合钱包生命周期分析 + ILS 分数 = 更精确的内幕检测

## 局限性

- 仅一个 cluster 的评估，泛化性待验证
- 仅覆盖 resolution-settlement 窗口，交易历史不完整
